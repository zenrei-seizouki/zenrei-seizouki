# 『前例製造機』 事件v2 台本 15本

形式（CASES_V2_PLAN.md 先頭の【決定】に従う）:
1本 = 最初の事件（4行以内）＋ 判決文2枚（🟦 認める／🟥 認めない。各20字前後＋予告）＋ 続きの事件（判決文ごとに1件、計2件）＋ 100年後（見出し25字以内・エンディング名10字以内）。

凡例:
- 続きの事件の原告は「あなたの判決によれば〜」で判例を持ち出す。判例に従うか、ただし書きで例外を作るかでプレイヤーが迷う内容。
- 原告は 猫・犬・カラス・ハト・金魚・子ども・老人・会社員・政治家・会社・町内会・政府・ロボット掃除機・自販機・AI のいずれか。
- 動物の原告には「通訳」を付ける（既存の猫のゴマ・猫のミケと同じ書き方）。

## 1. 骨なし手羽先事件（表示どおり）

### 最初の事件
**原告: 手羽先が好きな老人（78）**
- 居酒屋で「骨なし手羽先」を頼んだ。中身は胸肉だった。
- 手羽の肉が、ひとかけらも入っておらん。

**被告: 居酒屋チェーン・店長**
- 「骨なし」は、守りました。
- 手羽先から骨を抜くと、残るのは皮だけです。皮だけ出したら、もっと怒られます。

### 判決文
- 🟦 **名前に書いた物は、中に入れなければならない**
  - → たい焼き屋がざわついている
- 🟥 **食べ物の名前は、中身の約束ではない**
  - → 「無農薬」の八百屋がほっとしている

### 続きの事件
**🟦のあと: たい焼き事件**
- 原告: 小2の子ども
  - あなたの判決によれば、名前に書いた物は中に入れなければなりません。
  - たい焼きを3つ買って、3つとも割りました。タイが入っていません。
- 被告: たい焼き屋・店主
  - タイを入れたら、あんこの行き場がなくなります。
  - それと、お隣の「人形焼」の店主が、さっきから顔が青いです。

**🟥のあと: 本当に無農薬の爺さん事件**
- 原告: 畑を40年やっている老人
  - あなたの判決によれば、食べ物の名前は中身の約束ではないそうじゃ。
  - それで隣の八百屋が、「無農薬トマト」に堂々と農薬をかけておる。わしのは本当に無農薬じゃが、客が「どうせ同じじゃろ」と買わなくなった。
  - 八百屋に看板を下ろさせてくれ。
- 被告: 八百屋
  - 判決のとおりにしているだけです。
  - それと、おじいさんの「無農薬」は、どうやって証明するんです？

### 100年後
- 🟦 見出し: **きつねうどん、本物のキツネ入りが義務に** ／ エンディング: **名は体を表す国**
- 🟥 見出し: **「無料」の看板で入場料3千円、全て合法に** ／ エンディング: **言葉のあやの国**

## 7. 越境した枝事件（占有）

### 判決文
- 🟦 **境界を越えて張り出した物は、越えられた側の物**
  - → 隣のマンションの管理会社が、影の長さを測っている
- 🟥 **張り出していても、根元の持ち主の物のまま**
  - → 隣家の玄関に、落ち葉の袋が積まれ始めている

### 続きの事件
**🟦のあと: マンションの影事件**
- 原告: 公園前町内会
  - あなたの判決によれば、境界を越えて張り出した物は、越えられた側の物です。
  - 隣のマンションの影が、昼過ぎから町内の公園に張り出しています。影ごと、マンションをください。
- 被告: マンション管理会社
  - 影は、物ではありません。
  - それに、夕方は公園の木の影がうちのロビーに来ています。木をいただきます。

**🟥のあと: 落ち葉を返しに行った事件**
- 原告: 柿本ヨシオ（79）
  - あなたの判決によれば、張り出した枝は根元の持ち主の物じゃ。ならば、落ち葉も持ち主の物じゃろう。

- 被告: 隣家の夫婦
  - 玄関が、開きません。
  - それと、張り出した枝の柿を30年食べていた件は、まだ訴えていません。

### 100年後

## 自己評価

### 自信がある上位3本
1. **#1 骨なし手羽先事件** — 最初の事件が1行で言い切れて、「皮だけ出したら、もっと怒られます」の被告の一言で落ちる。🟦の続き（たい焼き）は笑い、🟥の続き（本当に無農薬の爺さん）は「判例に従うと正直者が損をする」ので本気で迷える。表示どおり争点の導入として一番分かりやすい。
2. **#3 罰金の看板事件** — 🟦の続き（子ども部屋のドア・母が自分に払う）は判例が家庭に返ってくる気持ちよさがあり、🟥の続き（崖の救助費3千万円）は「看板には縛られない」と言い切った自分に政府が返しに来る。笑いと迷いが両方の枝にある。
3. **#12 AIチャットボットの割引事件** — 「今さっき同じAIに聞いたら、会社に責任があると答えました」の一言が強い。🟦の続きで自販機が原告になって会社に「嘘をつかせないで」と言うのはこのゲームにしかできない絵で、Xに貼りやすい。

### 弱いと思う2本
1. **#10 月の土地事件** — 🟥の判決文「誰も住めない場所は、誰の物にもならない」が最初の事件（月の所有届）からやや飛ぶ。🟥の続き（沼の埋め立て）も登記の話が混ざって3秒で分かりにくい。🟥側を「届を出しても、手の届かない物は誰の物にもならない」に寄せ、続きを「屋上の空」「隣の家の上の空」のような身近な物に差し替える案がある。
2. **#13 動物が原告の訴訟事件** — 題材の性質上、🟥の続き（川の代わりに町内会が来る）が「迷う」より「それはそう」に近く、ただし書きの出番が薄い。🟦の続き（金魚が飼い主だけ訴える）は良いが、🟥側はもっと困る原告（例: AIが「私は会社の物だから会社として訴える」と主張する）に替える余地がある。
